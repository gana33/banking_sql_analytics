# 🏦 Banking Data Analytics Using MySQL

## 📌 Project Overview
This project focuses on analysing banking operations using MySQL to solve real-world business problems and generate meaningful business insights.

## 🗄️ Database Structure
The database consists of 8 relational tables:
- Branches
- Customers
- Accounts
- Account Types
- Transactions
- Transaction Types
- Loans
- Loan Payments

## 📈 Business Analysis Modules

### 1. Branch Analysis
- Branch-wise transaction performance
- Monthly transaction growth and decline
- Branch ranking within states
- Branch contribution to total transaction value

### 2. Customer Analysis
- Top customers by transaction value
- Customer transaction behaviour
- Inactive customer identification
- Customer activity and retention analysis

### 3. Transaction Analysis
- Transaction trends and patterns
- Channel-wise transaction performance
- Transaction success and failure rates
- Unusual transaction pattern identification

### 4. Account Analysis
- Account type distribution
- Dormant account identification
- Account status analysis
- Average opening balance by account type

### 5. Loan Analysis
- Loan portfolio analysis
- Loan repayment performance
- Loan delinquency analysis
- Branch-wise loan exposure

## 🎯 Key Performance Indicators (KPIs)
- Total Transaction Value
- Total Transaction Count
- Average Transaction Value
- Transaction Success Rate
- Transaction Failure Rate
- Month-over-Month Growth %
- Branch Contribution %
- Customer Activity Rate
- Dormant Account Rate
- Loan Repayment Rate
- Loan Delinquency Rate

## 🛠️ Technical Skills
- MySQL
- Joins and Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- RANK(), DENSE_RANK() and LAG()
- CASE WHEN
- Date and Time Functions

## 🎯 Project Objective
To apply SQL skills to real-world banking business scenarios, analyse operational performance, identify trends and convert raw data into actionable business insights.
